## Описание проекта
Программный комплекс предназначен для учета серверных узлов, контроля загрузки вычислительных ресурсов (CPU, RAM, задержка сети) и проведения вычислительных экспериментов по моделированию пиковой нагрузки на кластер.

## Состав репозитория
* `server_monitor_v1.py` — Редакция 1.0: базовое оконное приложение (GUI на Tkinter) для регистрации серверов в базе данных SQLite (`servers_v1.db`) и первичного расчета статуса узлов.
* `server_monitor_v2.py` — Редакция 2.0: финальная корпоративная версия с авторизацией администратора, ролевой привязкой серверов, фильтрацией, экспортом отчетов в CSV и модулем нагрузочного стресс-тестирования (`servers_v2.db`).
* `servers_v1.db`, `servers_v2.db` — локальные реляционные базы данных SQLite с тестовыми наборами серверной инфраструктуры.
* `user_guide.txt` — полное руководство пользователя к окончательной версии программного продукта.

## Технологический стек
* **Язык программирования:** Python 3.x
* **Графический интерфейс:** Tkinter / ttk
* **База данных:** SQLite3

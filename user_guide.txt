РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
Программный инструмент для тестирования чисел на простоту с сохранением результатов в базе данных SQLite (Редакция 2)
1. Введение
1.1. Область применения
Данное программное обеспечение предназначено для проведения вычислительных тестов, оценки эффективности алгоритмов определения простых чисел и анализа скорости обработки данных при взаимодействии с локальными реляционными базами данных.
1.2. Краткое описание возможностей
• Создание набора из 5000 случайных целых чисел в диапазоне от 1000 до 50000.
• Эффективная проверка каждого числа на простоту путем перебора делителей до его квадратного корня (с использованием модуля math.sqrt(n)).
• Автоматическое создание локальной базы данных SQLite с именем experiment_v2.db и таблицы results (поля id, number, is_prime).
• Пакетная запись результатов вычислений в базу данных с помощью оптимизированного метода executemany().
• Измерение и отображение общего времени выполнения всего вычислительного процесса в консоли.
1.3. Уровень подготовки пользователей
Для работы с программой необходимы базовые навыки использования персонального компьютера под управлением ОС Windows или Linux, умение работать с файлами и папками, а также способность запускать скрипты через командную строку (терминал) или среду разработки (IDE). Специальные знания в области администрирования и управления базами данных не требуются.
1.4. Перечень эксплуатационной документации
• Настоящий документ: «Руководство пользователя» (user_guide.txt).
• Исходный код программного модуля: version_2.py.
• Справочная документация по стандартным библиотекам Python (sqlite3, math, random, time).
2. Назначение и условия применения
2.1. Виды деятельности и функции
Программа выполняет следующие функции автоматизированного тестирования производительности (бенчмаркинга) и логирования:
• Генерация тестовой выборки числовых данных;
• Математическая обработка и проверка сгенерированных данных;
• Систематизированное сохранение полученных результатов в файл реляционной базы данных.
2.2. Программные и аппаратные требования к системе
• Операционная система: Windows 10/11, Linux или macOS.
• Процессор: Минимум 2 ядра с тактовой частотой от 1.5 ГГц и выше.
• Оперативная память (ОЗУ): Не менее 2 ГБ.
• Свободное место на диске: Не менее 50 МБ (для установки интерпретатора и хранения файлов базы данных).
• Программное обеспечение: Установленный интерпретатор Python версии 3.8 или выше, включая стандартные встроенные модули (sqlite3, time, random, math).
3. Подготовка к работе
3.1. Состав дистрибутива
Программный продукт включает в себя следующие компоненты:
• Основной исполняемый файл программы version_2.py (Редакция 2).
• Файл эксплуатационной документации user_guide.txt.
• Файл базы данных experiment_v2.db (формируется автоматически при первом запуске).
3.2. Запуск системы
1. Откройте командную строку (терминал, PowerShell или встроенный терминал в вашей IDE).
2. Перейдите в директорию, где находятся файлы проекта, используя команду cd путь_к_папке.
3. Запустите программный модуль командой: python version_2.py
3.3. Проверка работоспособности
Успешный запуск программы подтверждается появлением в консоли приветственного сообщения:
Запуск Версии 2 (Оптимизированные вычисления и пакетная запись)...
После завершения работы в консоль выводится итоговое время выполнения (около 0.15–0.20 сек), а в корневой директории проекта появляется непустой файл базы данных experiment_v2.db.
4. Описание операций
Операция 1: Проведение вычислительного эксперимента и пакетная запись данных
• Наименование: Запуск цикла генерации, вычисления простых чисел и сохранения результатов в БД.
• Условия выполнения: Наличие установленного интерпретатора Python 3.8+, наличие прав на чтение и запись файлов в рабочей директории проекта.
• Подготовительные действия: Убедиться, что файл experiment_v2.db не заблокирован сторонними приложениями (например, программами для просмотра баз данных).
• Основные действия: Пользователь запускает скрипт version_2.py. Программа фиксирует время старта, создает список из 5000 случайных чисел и проверяет каждое на простоту методом перебора до квадратного корня. Собранные кортежи данных передаются методу executemany() для пакетной вставки в таблицу results базы данных experiment_v2.db.
• Заключительные действия: Программа фиксирует транзакцию (commit), закрывает соединение с базой данных (close), останавливает таймер и выводит общее время работы в консоль.
• Ресурсы, расходуемые на операцию: Оперативная память (около 15–20 МБ в процессе работы), процессорное время (~0.17 сек), дисковое пространство (~150 КБ на 5000 записей в файле БД).
5. Аварийные ситуации
• Ошибка запуска (ModuleNotFoundError или SyntaxError): Возникает при использовании устаревшей версии интерпретатора или некорректной настройке среды. Действия по устранению: Убедитесь, что установлен Python версии 3.8 или выше и путь к исполняемому файлу добавлен в системную переменную PATH.
• Ошибка блокировки или доступа к файлу БД (sqlite3.OperationalError: database is locked или PermissionError): Возникает, если файл experiment_v2.db открыт в другой программе или у пользователя нет прав на запись в текущую папку. Действия по устранению: Закройте сторонние программы, работающие с файлом БД, либо перенесите папку проекта в пользовательский каталог с полными правами доступа (например, в «Документы»).
• Отсутствие результатов в БД: Если после выполнения скрипта таблица пуста, убедитесь, что программа завершилась корректно без принудительного прерывания (Ctrl+C) до выполнения команды фиксации транзакции.
6. Рекомендации по освоению
• Для наглядной оценки эффективности оптимизации рекомендуется сначала запустить первую редакцию программы (version_1.py) и сравнить время её выполнения со второй редакцией (version_2.py).
• Для быстрого просмотра записанных результатов без установки дополнительных программ можно использовать встроенную утилиту SQLite из терминала: выполните команду sqlite3 experiment_v2.db, а затем введите SQL-запрос SELECT * FROM results LIMIT 10;.
• При необходимости изменить параметры эксперимента (количество генерируемых чисел или их диапазон) достаточно отредактировать аргументы функций random.randint(1000, 50000) и range(5000) в коде скрипта version_2.py.
Заключение
Данный программный модуль предоставляет удобный и быстрый инструмент для проведения вычислительных экспериментов и оценки производительности алгоритмов проверки чисел на простоту с эффективной пакетной записью результатов в локальную базу данных SQLite.

РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
Программа для проведения вычислительного эксперимента (Версия 2)

1. Описание программы:
Программа генерирует массив случайных чисел, выполняет оптимизированную проверку на простоту и осуществляет пакетную запись результатов в базу данных SQLite.

2. Системные требования:
- Интерпретатор Python версии 3.8 или выше.
- Встроенный модуль sqlite3.

3. Инструкция по запуску:
- Откройте терминал в папке с проектом.
- Выполните команду: python version_2.py

4. Результат работы:
В консоль выводится время выполнения эксперимента (~0.17 сек). В папке проекта формируется файл базы данных "experiment_v2.db" с таблицей результатов результатов.
